# LOG

Человекочитаемый журнал работы. Каждая сессия Claude Code дописывает сюда, что
сделала, какие числа получила и что осталось. Машинный лог всех вызовов
инструментов пишется хуком в `logs/actions.jsonl` (см. `.claude/settings.json`).

Правило: запись после каждого законченного шага, не в конце сессии.

## 2026-09-28 · данные, лестница подходов, первые скрипты

### Разбор данных (dev)
- Диалог = декомпозиция одного поста Stack Exchange (`original_query`, ~280 слов) на
  3–5 реплик по ~18 слов, HTML нет. История в формате `Q: … A: …` **включает ответы**.
- Глубина: T1 211, T2 211, T3 211, T4 121, T5+ 104. Среди 647 реплик T2+: золото ==
  предыдущей у 41 %, ⊆ объединению прошлых у 70 %.
- Документы короткие: медиана 20 слов, p90 160, >512 слов — 0 %.
- **Утечка:** в drones, hardware, law, medicalsciences, politics `doc_id` содержит id
  диалога (`law_ex_111150_doc_0`). doc_id моделям не показывать. Вопрос организаторам в NOTES.
- Поля `subquestion_reasoning`, `original_query`, `turns[].answer` — аннотация, в поиске не
  используем (NOTES).

### Литература
- RECOR (arXiv:2601.05461), Таблица 3: DIVER-4B +History .545 против BM25 .446; GPT-4o
  rewrite без истории .288 (хуже истории); +Reasoning — oracle, +.04. Генерация:
  Oracle .874 / Retrieved .850 / NoRetrieval .816 — агрегированное 2b-vs-2c у них есть (NOTES).
- BRIGHT-репродукция (arXiv:2509.02558): лучшая связка Reason-Embed-4B + listwise gpt-oss-120b.
- Лестница B0–B4, S1–S7 записана в CLAUDE.md §6 с ожидаемыми числами.

### Код
- `scripts/retrieve.py` — первая стадия: BM25 (класс из кита) или плотный
  (sentence-transformers, кэш эмбеддингов в `data/index/<модель>/<домен>.npy`).
  Представления запроса: query / hist / rewrite / rewrite_hist.
- `scripts/fuse.py` — RRF по прогонам и память диалога (`--memory-decay`).
- `.env` (в .gitignore) с AIRI_BASE_URL / AIRI_API_KEY из соседнего проекта.
- Установлен sentence-transformers 6.1.0.

### Прогоны

  retrieve.py, dev, 67 с. **Не проскорены** — должны дать 0.1827 / 0.4379.

### Заблокировано / решения
- **AIRI** (`inference.airi.net:46783`): TCP проходит, TLS-рукопожатие таймаутится.
  Похоже на внутреннюю сеть / VPN. Блокирует LLM-ступени через AIRI.
- **Решение:** тяжёлые вычисления (эмбеддинги корпуса, реранкеры) — не на этом ноуте,
  а в Colab или на арендованном GPU. Локально только BM25, RRF, скоринг, API-вызовы.
- **Решение:** переписывание запросов делать через Claude API, а не AIRI. Ключа
  `ANTHROPIC_API_KEY` в окружении нет (есть только `ANTHROPIC_BASE_URL`); проверить
  `ant auth status` или завести ключ.
- **Требование:** все действия логировать в папке проекта. Сделано: `LOG.md` (этот файл)
  + хук PostToolUse → `logs/actions.jsonl`.
