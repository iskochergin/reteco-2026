## 2026-09-28 · разбор задачи, схема, каталог подходов

Сессия объяснений: схема решения в Figma (реплика → запрос → поиск → список

### Эксперимент на одной реплике (law ex_111150 turn 4)
Место золотого документа среди 20 027 при BM25. Реплика про контракты
исполнителей, история про копирайт; золото doc_3 «transfer of rights from
performers to producers».

| вариант запроса | слов | место золота |
|---|---|---|
| A только вопрос | 19 | 174 |
| B вопрос + вся история (официальный) | 298 | >1000 |
| B1 + последняя пара Q/A | 110 | >1000 |

| E гипотетический ответ Sonnet | 73 | 884 |

Вывод: на смене темы история хоронит золото; переписывание местоимений не
помогает, потому что BM25 не видит синонимов (owners ≠ producers);
гипотетический ответ двигает, но мало. Это одна трудная реплика, не
статистика. Лекарство по литературе: Topic Switch (CHIQ) и поиск по смыслу.

### Claude CLI работает
`env -u ANTHROPIC_BASE_URL -u ANTHROPIC_API_KEY -u ANTHROPIC_AUTH_TOKEN claude -p --model sonnet --tools "" --no-session-persistence "<prompt>" < /dev/null`
после `/login` в интерактивном `claude`. Токен протух один раз, лечится
повторным `/login`. ~6 с на вызов; на 858 реплик батчить по 10-20 в вызов.

### Литература и каталоги
Проведён поиск по двум линиям: разговорный поиск и reasoning-поиск.
Результат в docs/plan.md (каталог формулировок запроса, каталог поиска,
рецепты лидеров DIVER / BGE-Reasoner / iKAT-2025, матрица «что можем по
железу») и docs/sources.md (все ссылки). Главные поправки к плану:
реранк даёт +0.09…0.12, больше переписывания; RRF до реранка; слияние может
